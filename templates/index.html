About

Software engineer based in the UK. I am particularly interested in C++, software architecture and emulators.

I started in electronics and signal processing, and now write safety-critical embedded firmware, mostly in modern C++. I like working close to the hardware, and I learn best by building things from first principles. Current projects include a cycle-accurate Game Boy Color emulator, a custom oscilloscope-style trace viewer for an STM32 and a mini-chess game which is <1kB in size.

Away from the keyboard I compete in powerlifting and play chess.
